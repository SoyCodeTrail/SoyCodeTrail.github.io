项目简介

一个全功能的学习平台网站，包含技术博客、英语学习、编程课程、本地生活、龙虾社区等多个模块。支持 Markdown 写文章 + 脚本一键发布到 Supabase。

技术亮点

  • 全站 Supabase 驱动：技术博客、本地生活、龙虾资讯、AI 课程全部动态管理
  • 一键发布系统：本地写 Markdown，跑一条命令自动发布到网站
  • 多模块架构：5 大技术方向 + 英语学习 + 编程课程 + 本地生活
  • HTTPS + 域名：Let’s Encrypt 证书，soycodetrail.top

开发过程

从一台 2 核 2G 的腾讯云服务器开始，用 Vue3 + Supabase 搭建。AI 帮助完成了约 90% 的代码编写和调试工作。

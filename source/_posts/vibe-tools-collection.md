## 工具对比

| 工具 | 定位 | 费用 | 适合 |
|------|------|------|------|
| Cursor | 最成熟 AI IDE | $20/月 | 有经验的工程师 |
| Trae | 中文 AI IDE | 永久免费 | 初学者、中文开发者 |
| CodeBuddy | 腾讯出品 | 免费 | VS Code 用户 |
| ZCode | 国产 Agent 工具 | 免费 | 进阶开发 |
| Claude Code | 命令行 Agent | 按 Token 计费 | 大型项目 |

## 选择建议

- 零基础入门：Trae（免费 + 中文）
- 日常开发：Cursor 或 CodeBuddy
- 大型项目：Claude Code
- 团队协作：ZCode
